Adi's WonderSteps v0.4.5 — static deploy

Run:
  python -m http.server 8080
Then open:
  http://localhost:8080

Brand/world configuration:
  config/game-content.json

Movement:
  Right = right-facing Adi/Dev side art
  Left  = mirrored side art
  Up/down = forward walking art

Controls:
  WASD / arrows = move
  E = interact
  Q = quest panel
  H = companion panel
  M = map
  B = Memory Book
